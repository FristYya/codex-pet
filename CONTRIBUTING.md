# Contributing

Thanks for helping improve Codex Pet.

1. Keep changes focused on the current milestone.
2. Add or update tests before changing behavior.
3. Run `pnpm build` and the relevant Rust tests before submitting a change.
4. Use Conventional Commits such as `feat: add quota parser`.
5. Never commit credentials, Codex account data, local logs, prompts, conversations, or project source captured from another workspace.

Bug reports should include operating-system and Codex CLI versions, but must not include raw Codex logs or authentication files.
