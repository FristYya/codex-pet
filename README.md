# Codex Pet

Codex Pet 是一款面向 Windows 的本地额度监控桌宠，以轻量悬浮窗显示 Codex 的 5 小时和每周额度。它会优先复用系统中兼容且已登录的 Codex 运行时；如果没有可用的登录状态，则使用安装包附带的官方 Codex 运行时，并通过系统浏览器引导你登录 ChatGPT。无需注册 Codex Pet 账号。

Codex Pet 是独立开源项目，不是 OpenAI 官方产品。

## 核心功能

- 显示 5 小时和每周额度的剩余比例、重置时间与详细信息。
- 启动时读取真实额度；收到额度更新事件时立即刷新，并每 60 秒自动刷新一次。
- 点击桌宠可展开或收起详情；按住或拖动桌宠可移动位置。
- 保存桌宠位置，并在多显示器、显示器拔插和不同显示缩放比例下尽力恢复到可见区域。
- 通过系统托盘显示或隐藏桌宠、手动刷新、锁定位置、设置始终置顶、启用开机启动或退出应用。

## 系统要求

- Windows 10 或 Windows 11（x64）。
- 无需预先安装 Codex CLI，也无需打开终端或执行 `codex login`。

Codex Pet 不提供密码、Cookie 或访问令牌输入框，也不会解析或展示认证文件。应用界面和 Rust 适配层不会读取认证内容；随包附带的官方 Codex 运行时会在 Codex Pet 专用的用户数据目录中管理登录状态，并通过本机 Codex App Server 读取额度。已有兼容登录状态时会直接复用；否则应用会引导你在系统浏览器中登录 ChatGPT。

## 安装

1. 打开 [GitHub 发布页](https://github.com/FristYya/codex-pet/releases)，下载最新版本的 Windows 安装包。
2. 推荐普通用户下载 NSIS 安装程序（`.exe`），运行并按 Windows 提示完成安装。
3. 从开始菜单打开 **Codex Pet**。
4. 如果应用提示需要登录，点击“登录 ChatGPT”，并在系统浏览器中完成登录。
5. 返回桌面查看 5 小时和每周额度；以后重新打开应用时会尝试恢复已有登录状态。

同一版本提供两种安装包：

- **NSIS（`.exe`）**：推荐普通用户使用。
- **MSI（`.msi`）**：适合偏好 Windows 安装程序或需要企业部署的用户。

需要卸载时，请在 Windows“已安装的应用”中选择 **Codex Pet** 并卸载，也可以使用安装程序提供的卸载入口。Codex Pet 专用目录中的登录数据默认保留；卸载不会改动系统 Codex 或用户项目。

## 使用方式

- **拖动与展开**：短按桌宠可展开或收起详情；按住约 250 毫秒，或移动超过约 6 像素，即可拖动桌宠。刷新按钮不会触发拖动。
- **系统托盘**：右键任务栏通知区域中的 Codex Pet 图标，可显示或隐藏桌宠、手动刷新、调整置顶状态或退出。
- **锁定位置**：在系统托盘菜单中选择“锁定位置”后，桌宠会忽略鼠标操作以避免误触；再次从系统托盘取消锁定即可恢复操作。
- **开机自动启动**：在系统托盘菜单中勾选“开机自动启动”。正式安装版本会在登录 Windows 后启动已安装的 Codex Pet；取消勾选即可关闭。

## 本地运行与隐私

Codex Pet 全程在本机运行：没有 Codex Pet 后端或遥测，也不会上传额度数据。应用只向本机 Codex App Server 发起额度读取请求，不会启动模型对话或发送提示词。

应用界面和 Rust 适配层不会读取、记录或展示密码、访问令牌、Cookie、`auth.json` 或会话内容。官方 Codex 运行时会在专用的 `CODEX_HOME` 目录中管理登录数据，以便本机 App Server 恢复登录。该目录位于 Codex Pet 的用户级应用数据目录，卸载后默认保留；应用不会修改系统 Codex 或用户项目。

## 当前限制

- v0.1.0 正式支持 Windows 10/11 x64；macOS 尚未作为正式支持平台发布。
- 安装包内的 Codex 运行时固定为经过项目验证的 `@openai/codex@0.156.1-win32-x64` 版本。
- 额度显示依赖本机 Codex App Server 和可用的 Codex 账户登录状态。
- 多显示器和显示缩放恢复已具备保护逻辑，但不同真实设备组合的行为仍可能有所差异。
- 当前不提供额度历史、自动更新、独立设置窗口、额外动画或皮肤，也不支持 Claude 或 Gemini。

## 本地开发与验证

开发环境需要 Node.js、pnpm、Rust 稳定版工具链，以及 Tauri 2 所需的 Windows 构建环境。

```powershell
pnpm install
pnpm run prepare-runtime
pnpm test --run
pnpm build
Set-Location src-tauri
cargo test
cargo clippy -- -D warnings
```
